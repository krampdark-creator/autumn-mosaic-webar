# Осінь оживає — WebAR

Архів містить вебсторінку для AR у Safari/Chrome без Snapchat, відео та зображення для розпізнавання.

Перед запуском створіть `target.mind`: відкрийте https://hiukim.github.io/mind-ar-js-doc/tools/compile/, завантажте `mosaic-target.jpg` (краще замінити його фото саме тієї мозаїки на стіні), скомпілюйте та збережіть результат як `target.mind` у цій папці. Потім завантажте всі файли на HTTPS-хостинг.

Стара надрукована QR-код-адреса й далі веде на Imersum. Без доступу до старої адреси її неможливо самостійно перенаправити. Після публікації можна створити новий QR-код. Деталі — у README_RU.md.
