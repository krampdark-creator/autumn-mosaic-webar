# Осень оживает — WebAR project

Проект веб-AR для Safari/Chrome без Snapchat. Содержит страницу, анимацию и изображение для image tracking.

## Важные файлы
- `index.html` — веб-страница на MindAR + Three.js (библиотеки подключаются через CDN).
- `autumn-animation.mp4` — предоставленное видео.
- `mosaic-target.jpg` — изображение-цель для распознавания. Сейчас это чистая иллюстрация из материалов проекта; для точного трекинга лучше заменить фронтальным фото именно той мозаики, что напечатана/нарисована на стене, если оно отличается.
- `target.mind` — **нужно сгенерировать перед запуском**, компилируется из выбранного изображения.

## Создание target.mind
1. Откройте компилятор MindAR: https://hiukim.github.io/mind-ar-js-doc/tools/compile/
2. Загрузите `mosaic-target.jpg` (или замените его фото реальной мозаики, снятой прямо спереди без бликов).
3. Скомпилируйте изображение и скачайте `.mind` файл.
4. Положите его в эту папку и переименуйте в `target.mind`.

## Публикация
1. Загрузите все файлы в статический HTTPS-хостинг (например, Netlify Drop, GitHub Pages или Cloudflare Pages).
2. Откройте полученную HTTPS-ссылку на телефоне, нажмите «Запустить AR» и разрешите камеру.
3. Проверьте распознавание на реальной стене.

## Ограничения
- Этот архив — готовая основа проекта, но не уже опубликованный сайт. Из чата нельзя выдать работающий публичный URL без размещения файлов на хостинге.
- Старый напечатанный QR ведёт на Imersum. Он не начнёт вести на новую страницу, пока владелец старого адреса не изменит перенаправление. После публикации можно сделать новый QR для новой HTTPS-ссылки.
- Текущий код размещает видео целиком на плоскости распознанного изображения. Если в видео есть полный фон, он будет выглядеть прямоугольным видео поверх мозаики, а не отдельными листьями. Для органичного AR-эффекта видео должно совпадать по композиции с целевой мозаикой или быть подготовлено с прозрачностью/отдельными слоями.
